## Возможности

**Библиотека**
- Добавление песен по файлам или целыми папками; теги читаются из ID3/Vorbis/MP4 (название, исполнитель, альбом, номер трека, длительность, обложка).
- Большие библиотеки: списки виртуализированы, теги читаются порциями в фоне — окно не замирает.
- Мгновенный поиск по названию и исполнителю.
- Форматы: `mp3`, `flac`, `m4a`, `aac`, `wav`, `wma` (декодирование силами Windows Media Foundation).

**Альбомы и плейлисты**
- Автоматическая группировка в альбомы (от двух песен), остальное собирается в «Остальные песни».
- Собственные плейлисты с редактором, обложками и перестановкой.
- Очередь воспроизведения следует за тем, откуда запущен трек: основной список, альбом или плейлист.

**Режим «Хаос»**
- Случайное перемешивание очереди с настройками: количество треков и выбор исполнителя.

**Удобство**
- Плавная прокрутка с субпиксельной точностью (собственный движок), подсветка строк не «прыгает» при прокрутке.
- Горячие клавиши: `Пробел` — пауза, `←` / `→` — предыдущий / следующий, `A` / `D` — перемотка назад / вперёд (при удержании ускоряется).
- Полное сохранение состояния: библиотека, плейлисты, текущий трек и позиция, громкость, режим, положение и размер окна.

**Интеграция с Windows**
- Панель «Сейчас играет» и мультимедийные клавиши (SMTC).
- Открытие файлов из проводника (двойной клик, «Открыть с помощью»), один запущенный экземпляр.
- Регистрация в «Приложения по умолчанию» для аудиоформатов (в установщике).

## Скачать

Готовые сборки — на странице [Releases](../../releases):

| Файл | Для чего |
|---|---|
| `MyPlayer-<версия>-win-x64.msi` | Обычная установка в систему: меню «Пуск», ассоциации файлов, обновление поверх старой версии. Данные хранятся в `%AppData%\MyPlayer`. |
| `MyPlayer-<версия>-portable-win-x64.zip` | Портативная версия: распаковать и запустить, ничего не ставится. Данные лежат в папке `Data` рядом с программой — удобно носить на флешке. |
| `SHA256SUMS.txt` | Контрольные суммы файлов. |

Среду .NET устанавливать не нужно — она уже входит в сборки.

> Приложение пока не подписано цифровой подписью, поэтому при первом запуске Windows SmartScreen может показать предупреждение: **Подробнее → Выполнить в любом случае**.

**Требования:** Windows 10 (1809 и новее) или Windows 11, x64.

## Сборка из исходников

Нужны Visual Studio 2022 (компонент «Разработка классических приложений .NET») или .NET SDK 8.

```powershell
git clone <адрес репозитория>
cd MyPlayer
dotnet run --project MyPlayerMVVM\MyPlayer.csproj
```

Или откройте `MyPlayer.sln` в Visual Studio и нажмите <kbd>F5</kbd>.

## Устройство проекта

Приложение построено по MVVM; каждая возможность живёт в отдельном модуле (`partial`-классы и самостоятельные сервисы), поэтому новое добавляется без переписывания старого.

```
MyPlayerMVVM/
├── Models/               Track, Album, Playlist
├── ViewModels/           MainViewModel (+ partial-модули: Seek, Persistence, AddFiles,
│                         OtherSongs, MediaSession, OpenExternal), PlaylistsViewModel
├── Views/                MainWindow (XAML + code-behind только для представления)
├── Controls/             WindowTitleBar, InlineEditText, SquareGrid
├── Behaviors/            SmoothScrollBehavior (движок прокрутки), PlayerHotkeys, NavButton
├── Converters/           конвертеры значений для XAML
└── Services/
    ├── AudioPlayerService        обёртка над MediaPlayer (Media Foundation)
    ├── SystemMediaControls       «Сейчас играет» и медиаклавиши Windows
    ├── SingleInstance            один экземпляр + передача файлов из проводника
    ├── CoverCache                кэш обложек
    └── Persistence/              AppPaths, StateStore, CoverStore, модели состояния
installer/                WiX-проект MSI
scripts/                  сборка релизов
.github/workflows/        автосборка и публикация релиза по метке v*
```

**Ключевые решения**
- **Хранение данных.** Режим определяется файлом `portable.flag` рядом с программой: есть — всё в `Data` рядом с exe, нет — в `%AppData%\MyPlayer`. Запись атомарная (временный файл → подмена) с резервной копией `.bak`; автосохранение каждые 5 секунд пишет на диск только изменившееся.
- **Прокрутка.** Позиция догоняет цель через каскад из трёх фильтров первого порядка по точной формуле (не зависит от частоты кадров); дробная часть смещения отдаётся трансформацией, а смещение и раскладка применяются в одном кадре — без дрожания на медленной прокрутке.
- **Идентификаторы треков.** Стабильный Id из хеша пути — по нему плейлисты находят треки после перезапуска.
- **Звук.** Декодирование делает Windows (Media Foundation), поэтому в сборке нет собственных кодеков.

**Технологии:** .NET 8, WPF, MVVM, [TagLibSharp](https://github.com/mono/taglib-sharp), System.Text.Json, WiX Toolset 5, GitHub Actions.
